# Coach assets

Source for the skeleton Coach, its Exercise clips and its Accessories. Everything here is generated by code in Blender 5.2, is original, and ships under the repository's MIT license (ADR 0003). The Site loads only the copies in `public/assets/coach/` (ADR 0004).

## What the app can rely on

### Clip GLBs: one per Exercise

`public/assets/coach/coach_<clip>.glb`, where `<clip>` is `grave_rise`, `skeleton_jacks`, `coffin_push`, `stretch_side_reach` or `stretch_forward_fold`.

- One animation named `demo_loop`: in place, seamless, 30 fps.
- The Coach faces glTF +Z, stands on y = 0, and is about 1.8 m tall.
- Every clip uses the same rig. The joint names are `root`, `pelvis`, `spine`, `chest`, `neck`, `head`, then `shoulder|upper_arm|forearm|hand.L/.R` and `thigh|shin|foot|toe.L/.R`. `.L` is the Coach's own left.

### Coach color: tint one material

| Material | Use | Tint at runtime? |
|---|---|---|
| `CoachBone` | every bone | **Yes.** Set `material.color` to the Coach color. The default bone color is `#F5F0E3` (sRGB). |
| `CoachSocket` | eye sockets and nose | No. They stay dark. |

### Accessories: one extra file, attached to the `head` bone

`public/assets/coach/coach_accessories.glb` holds the same rig in its rest pose, with no animation. Each Accessory is a plain mesh node that is a direct child of `head`:

| Node | Accessory | Notes |
|---|---|---|
| `accessory_glowing_eyes` | Glowing eyes | Sits in the eye sockets. Hidden by the pumpkin head when both are on. |
| `accessory_witch_hat` | Witch hat | Use when the pumpkin head is **off**. |
| `accessory_witch_hat_on_pumpkin` | Witch hat | Use when the pumpkin head is **on**; it sits on the pumpkin. |
| `accessory_pumpkin_head` | Pumpkin head | Covers the whole skull. |

To equip an Accessory, add a clone of its node to the Coach's `head` bone and keep the node's own local transform:

```ts
const head = coachRoot.getObjectByName('head');
head.add(accessories.scene.getObjectByName('accessory_witch_hat').clone());
```

The `head` joint has the same rest transform in every GLB, so the Accessory follows every clip with no extra offset. Do this after the viewer has measured the Coach's bounds if the camera framing should ignore Accessories, or before if it should include them.

Accessory materials, never tinted: `CoachGlow` (emissive green, used by the eyes and the pumpkin's carved face) and `CoachAccessory` (colors come from vertex colors, so the material needs `vertexColors`; GLTFLoader sets this itself). With every Accessory on, the Coach uses 4 materials and about 4,800 triangles.

## Rebuild and check

Run from the repository root; `blender` is `C:\Program Files\Blender Foundation\Blender 5.2\blender.exe`.

```
blender -b --factory-startup --python assets/coach/build_coach.py [-- <clip>|accessories ...]
blender -b --factory-startup --python assets/coach/verify_coach.py -- assets/coach/coach_<clip>.glb [--planted BONES|none] [--render DIR]
blender -b --factory-startup --python assets/coach/check_accessories.py [-- --render DIR]
blender -b --factory-startup --python assets/coach/render_stills.py [-- <clip> ...]
```

- `build_coach.py` writes `coach_<clip>.blend` and `.glb` (or `coach_accessories.*`) here, and copies each GLB to `public/assets/coach/`.
- `verify_coach.py` checks the budget (≤ 6 MB, ≤ 35k triangles, ≤ 4 materials), the clip, the loop, and that the root, feet, or hands stay planted. Use `--planted hand.L,hand.R,toe.L,toe.R` for `coffin_push` and `--planted none` for `skeleton_jacks`.
- `check_accessories.py` attaches every Accessory to every clip and fails if any of them cuts through the skull or touches the moving Coach on any frame.
- `render_stills.py` writes the 360 × 480 Still_Images to `public/assets/coach/stills/`.
