# Make the Coach and its animations ourselves in Blender

Kiroween requires a public GitHub repo containing all assets under an open-source license, but Mixamo's terms forbid distributing its raw character and animation files. So instead of the usual Mixamo pipeline, we build the skeleton Coach, its Accessories and every Exercise animation ourselves in Blender (driven through Blender MCP), which lets us publish them under the repo's license. If hand-made motion turns out too poor, the next fallback is CC0 assets, never Mixamo.
