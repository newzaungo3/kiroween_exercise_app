# No backend: all user data lives in the browser

The PRD specifies Supabase for accounts, synced workout history, consent and analytics. For the hackathon demo we drop the server entirely: workout history, Candy and Coach customisation are stored in the browser (localStorage), and there are no accounts. Clearing browser data or switching devices loses progress, which we accept for a demo; a Welcome gift of Candy covers judges arriving with an empty store.
