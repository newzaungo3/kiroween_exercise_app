# Build a Next.js web app, not a native mobile app

The PRD specifies React Native + Expo for iOS and Android. For the Kiroween hackathon (deadline 2026-12-04, solo builder new to React and 3D) we build a mobile-friendly Next.js web app with Three.js via React Three Fiber instead: judges open a link with no install, there is no app-store review, and 3D in the browser avoids the PRD's biggest risk (native GL/GLB loading on phones). A native app can be revisited after the hackathon.
